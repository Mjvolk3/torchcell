## 2026.09.27 - The three subgraph processors and the neighbor processor on one fixture

Five genes YAL001C to YAL005C (indices 0 to 4) on the physical path 0-1-2-3-4, which `to_cell_data` writes once per undirected edge plus the five self loops (nine positions), and a bipartite block of three reactions (r1 on genes 0 and 1 in subsystem Growth, r2 on gene 3, r3 with no genes) over three metabolites, with signed stoichiometry, `gpr` and `rmr` hyperedges and `w_growth` [1, 0, 0]. Perturbing gene 0 keeps genes [1, 2, 3, 4], drops the two edge positions touching 0 and relabels the seven survivors; r1 loses a gene and is removed, so `valid_reactions` is [1, 2]. Two records perturbing genes 0 and 3 leave only the gene-free r3. `SubgraphRepresentation` and `IncidenceSubgraphRepresentation` are compared store by store on the same input; `LazySubgraphRepresentation` keeps every node and edge and emits masks, and its mapping onto the subgraph output is asserted exactly (gene map = cumsum(mask) - 1 on the edges, the reaction map on `rmr`, and for `gpr` the rule that the subgraph keeps an edge exactly when the lazy mask and the reaction mask of its reaction both hold). Findings: `NeighborSubgraphRepresentation.process` raises `AttributeError: 'list' object has no attribute 'tolist'` on any perturbed input because `_process_gene_info` returns a list (graph_processor.py line 2481) and `_build_khop_subgraph` calls `.tolist()` on it (line 2491), so the k-hop pieces are tested through the tensor they accept; its `_process_metabolism` (lines 2557 to 2583) filters the reaction store to one node but copies the full `gpr` and `rmr` incidence, whose reaction column still reaches index 2; k-hop neighborhoods are asymmetric because `k_hop_subgraph` adds edge sources only and each undirected edge is stored once (from gene 2 one hop is {1, 2}); the lazy processor's `_add_reaction_data` (lines 1720 to 1723) ignores `w_growth` and recomputes zeros from a `subsystem` attribute the cell graph does not carry; the lazy class docstring (lines 1239 to 1246) promises filtered `node_ids`, `num_nodes` and an `x_pert` the code never writes; `build_cache` halves the incidence count as if every edge were listed twice, so self loops make a nine-edge graph report six (lines 1322 to 1329); `SubgraphRepresentation.process` returns the whole graph on an empty batch where the other processors raise, and omits the four `phenotype_stat_*` keys when no statistic is present (line 554) while `Perturbation` emits empty tensors, so mixed outputs would not collate.
