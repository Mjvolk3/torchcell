Planned scope: query the database for a dataset that has not been used for modeling
before, and apply the three steps that turn the query result into a modeling dataset.
A converter rewrites records of different experiment types into one common type.
Deduplication merges repeated measurements of the same genotype into one record.
Aggregation groups the records that share a genotype into one item. The notebook
applies each step in turn and shows what it changes.
