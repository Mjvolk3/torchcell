torchcell.utils

Shared helpers. paths resolves output directories relative to the current checkout (so a script run from a git worktree writes into that worktree); utils holds the repository-wide figure standards (the ordered plot palette, Nature panel widths in millimeters, savefig_true_size_svg() and apply_paper_style()); and file_lock provides FileLockHelper for locked JSON reads and writes.
