torchcell.tasks

Standardized benchmark tasks. A task pins one dataset, the genome its records are written against, one label and a set of pinned train, validation and test splits. load_task() is the one import a benchmark script needs; the test part of every split is locked until unlock_test() is called. The overview is at E. coli tasks.

Task and split objects

TaskSpec

What one benchmark task is: the dataset, the genome, the label and the metric.

BenchmarkTask

A processed benchmark task: samples, genes, labels, genome and pinned splits.

Split

One named split of a task: row indices of train and validation, test locked.

TestSplitLocked

Raised when the test part of a split is read before it is unlocked.

TestSplitWarning

Emitted every time the test part of a split is unlocked.

regression_metrics

Pearson, Spearman, R2, MSE and MAE of each target column.

E. coli tasks

load_task

The processed benchmark task name with its pinned splits.

build_task

Build a task from its dataset and genome, without splits.

open_dataset

Open the task's dataset with its loader (downloaded when TC_DATA_URL is set).

match_records

Match every record of dataset to genes of genome.

read_labels

Labels of the given records as (n, n_targets) and the target names.

write_splits

Write a split file (gzip CSV, byte-stable) and return its sha256.

read_splits

The pinned split file of a task, verified against SPLIT_SHA256.

Split functions

assign_groups

Assign every member to a part so that no group is divided.

random_split

Random split in which members that share a key stay together.

block_groups

Group members into n_blocks contiguous blocks of equal count by position.

pair_parts

Part of each gene pair from the parts of its two genes.

pair_novelty

Number of genes of each pair (0, 1 or 2) that are not training genes.

part_sizes

Number of members in each part.
