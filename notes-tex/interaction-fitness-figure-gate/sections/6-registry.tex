\section{The experiment registry\secstatus{todo}}
\label{sec:registry}

Shared protocol: the 030 S3 pool (arm R) or S3Q pool (arm Q); pinned validation and test
triples never in a loss; the checkpoint chosen on validation interaction Pearson; test
Pearson and Spearman, pooled and within screen; three seeds unless stated; paired by triple
against the named control over 2,000 bootstrap resamples. Every entry is \fstat{idea}
until its result file exists.
