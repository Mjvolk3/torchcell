torchcell.ontology
==================

.. module:: torchcell.ontology

.. currentmodule:: torchcell.ontology

Helpers for inspecting the torchcell BioCypher ontology. The ``print_*`` functions in ``tc_ontology`` print the ontology structure, a summary and the schema mappings; the ``mermaid_diagram`` module (not re-exported) renders the BioCypher schema as a Mermaid diagram.
