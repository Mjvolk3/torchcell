Planned scope: one worked modeling example with the Cell Graph Transformer (CGT), a
transformer model over the gene graphs of tutorial 4. The notebook trains it on one
dataset, compares it with the simple baselines of tutorial 6, and shows where it
succeeds and where it fails. CGT is only an example here: the other eight tutorials
are about the data, and any model can take its place.
