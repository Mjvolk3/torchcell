The map shows every class of the schema. Drag to pan and scroll to zoom.

- **Click a class** to see its fields and the served datasets whose records can hold it.
- **Click a dataset**, there or in the picker at the top, to light up the classes it
  uses. Its panel links to the dataset's page in the docs and to its loader's API
  reference.
- The address bar follows the selection, so a class or a dataset view can be linked.

The page-width button in the navbar gives the map the whole window.
