Findings the tests produced:

- `HeteroToDenseMask` padded `x` and `pos` but no other node tensor: its "pad all tensor attributes" loop iterated `dir(store)`, which does not list stored attributes. Fixed to `store.keys()` in this PR (one line, covered).
- `ListMLELoss` as implemented takes one `log_softmax` over the whole list, so -sum log_softmax = -sum(y) + n logsumexp(y) is invariant to the true ranking: the loss never reads `y_true`. It is live (`trainers/neo_regression.py`), so this is a bug, not a quirk. The implemented value is pinned, and `test_plackett_luce_value` asserts the paper's cumulative value (3.7208676519 on the fixture) as a strict xfail; fixing the loss flips both, which is the intended signal. The fix itself changes a live training loss and is left to its own PR.
- Seven loaders return `raw_file_names` as a bare `str` (`type: ignore[override]` against the base class's `list[str]`). A fix was written and reverted: its six `preprocess_raw` call sites run only under `--data`, so diff-cover scored the change 71% and would have blocked the PR. Pinned strictly in `STR_RAW`; the fix needs a synthetic-TSV `preprocess_raw` test first.
