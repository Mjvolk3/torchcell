Planned work is tracked as GitHub milestones, and individual tasks as GitHub issues.

- [Milestones](https://github.com/Mjvolk3/torchcell/milestones): groups of issues with
  a shared goal.
- [Issues](https://github.com/Mjvolk3/torchcell/issues): open and closed tasks, bug
  reports, and requests.
