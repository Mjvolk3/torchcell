\section{Queue order and clock\secstatus{todo}}
\label{sec:queue}

The mmli partition is one node with four A100s and every job takes all four, so the
campaign is a single chain in which each job starts when the previous one ends, whether it
succeeded or not. An S0 run of 30 epochs takes 7.5 hours (jobs 2408604 to 2408607) and an
S3 or S4 run of 50 epochs 33 hours (39.5 minutes per epoch, job 2409033).

The order follows the two claims. The S3 replicates on R come first, then the composite on
R at S0 (a day for all three seeds) and at S3, then the single-region replicates on Q, the
first S4 seed, the table-with-fitness baseline on Q, the S3 strict cells on Q with the two
representations alternating by seed so that a campaign stopped early is still balanced, and
the remaining S4 seeds.
