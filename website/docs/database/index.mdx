The TorchCell database is a Neo4j knowledge graph that stores the typed experiments of
every dataset. At release <ReleaseCount field="releaseDate" /> the served graph holds <ReleaseCount field="nDatasets" /> datasets and <ReleaseCount field="nExperiments" /> experiment records over <ReleaseCount field="nGenotypeEnvironmentPairs" /> distinct genotype-environment combinations. The two counts differ because an interaction score derived from a fitness measurement is a second record on the same combination: a digenic or trigenic interaction record sits beside the double or triple mutant fitness record it was computed from.
