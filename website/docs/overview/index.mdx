TorchCell is a Python library and a Neo4j knowledge graph for yeast genotype,
environment, and phenotype data. It records each published measurement as a typed
experiment: a pydantic `genotype x environment -> phenotype` object. The library needs
Python 3.13 or later.

The served knowledge graph holds 51 datasets and 52.7 million experiments at release
2026.09.21.
