Planned scope: fetch one built dataset through its loader, download the benchmark
split file for it, fit a model on the training records, write the predictions file for
the validation and test records, and upload it to get a score. The notebook covers the
whole path once, on one dataset, so that every later tutorial can start from data that
is already on disk. It follows the [training protocol](/benchmark/training-protocol).
