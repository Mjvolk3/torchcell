\section{Open\secstatus{todo}}
\label{sec:open}

\begin{itemize}
  \item Round 4 (jobs 2246 to 2248, three cells per GPU): the gated, forced and
    shuffled-$k_{cat}$ readouts at constraint scale 0 on the round-3 cell (batch 32, class
    weight, 200 epochs), paired by seed against it. The reads are the round-2 reads.
  \item FBA's growth ratio as an input to the transformer. The ladder's top rungs are
    frozen encodings with the four ratios appended (0.81 to 0.83), and neither half
    reaches that alone; a cell that concatenates the ratios to the readout, or carries
    them as a node feature, tests whether the transformer gains the same complement.
  \item The module's own hyperparameters have not been moved on this endpoint: the
    $k_{cat}$ tier (measured against predicted), the thermodynamic source, the
    parameterization (projection against nullspace), the number of alternations.
  \item Every cell here is width 12. The depth-against-width isolation (width 90 at one
    block, width 12 at two) has not run on the split-file protocol.
\end{itemize}
