## 2026.08.24 - Add a citation from a DOI, with a pinned citekey

`notes-tex/common/zotero_add_ref.py`

`references.bib` is GENERATED by `build_bib.py` from Zotero, so hand-editing it
is pointless: the next `make bib` overwrites it. The library is the source of
truth, which makes "cite a new paper" mean "put it in the library first". This
makes obeying that cheap.

Metadata comes from CrossRef rather than being typed, because a hand-entered
reference is a silent-corruption risk of exactly the kind the provenance rules
exist to prevent: a wrong volume or year is invisible in the built PDF.

Two things learned using it on 12 references:

- **Always check the printed first author against the citekey.** Five of the
  twelve keys guessed from a research summary named the wrong author (the
  summary said "Kildegaard", CrossRef says "Zun"). The script prints the first
  author for exactly this check.
- **`--emit-bibtex` exists because BBT's export endpoint can be down while
  Zotero is up.** `cayw` answered `ready` while
  `/better-bibtex/export/collection` returned 404 for every collection, so
  `make bib` failed. The items were already in Zotero with pinned keys, so
  emitting BibTeX and appending it kept the build correct until the export route
  recovered.

Targets the PERSONAL collection only; promotion to the shared group library is a
curation decision a person makes.
