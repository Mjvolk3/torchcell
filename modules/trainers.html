torchcell.trainers

PyTorch Lightning training tasks. The package exports the regression task (RegressionTask), a simple linear baseline, and two DCell tasks. The fit_int_* and int_* modules hold the tasks used by individual experiments and are imported by module path from the experiment scripts. Every class below is listed under the module that defines it.
