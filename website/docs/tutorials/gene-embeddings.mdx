Planned scope: compute a gene embedding dataset, which stores one fixed numeric vector
per gene, and combine several of them into a composite node embedding, which is the
single vector a model reads for each gene. The embeddings are the same ones the
benchmark baselines use; they are listed under [Encodings](/benchmark/encodings).
