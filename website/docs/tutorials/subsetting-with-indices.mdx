<StatusBadge status="planned" />

Planned scope: select part of a dataset without scanning every record. An index here
is a lookup computed once from the records and stored with the dataset, which maps a
property of a record to the positions of the records that have it. The notebook shows
which indices a dataset carries, how to take a subset through one of them, and how to
combine two of them.
