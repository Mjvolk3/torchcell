# compound_identity_inputs/bacterial_conditions.txt
# Source: issue #726 (the curator pass over the bacterial condition labels) and issue #860
# (the RCH2_defined_noCarbon medium Borchert 2024 names), 2026.10.10. Curated on this list
# alone and merged into the pinned table additively by
# experiments/036-dataset-fixes-before-kg-build/scripts/compound_curator_726_860.py, which
# also writes the per-label evidence (PubChem record, the source's CAS where it states one).
#
# SCOPE. Every label with a typed InChIKey gap (UNRESOLVED_PUBLIC, a single substance) in
# the built stores of the six datasets #726 and #860 name -- RbTnseqPrice2018Ecoli,
# CarbonSourceTong2020, GeneEssentialityGoodall2018, RnaseqLamoureux2023 and
# RnaseqPublicK12Lamoureux2023 (PRECISE-1K), RbTnseqBorchert2024 -- measured by
# bacterial_compound_identity_gaps.py; then every other gap label whose stores all lie in
# the set those rows already force a rebuild of (Girgis 2009, Choe 2025, Schmidt 2016 and
# others). Plus the three RCH2 base salts and the two RCH2 carbon sources the 20 dropped
# Borchert samples name that the table did not resolve (4-Hydroxyvalerate; Potassium
# acetate is already a Price 2018 label). The Wolfe's mixes stay mixtures in media.py (the
# Fang 2025 trace-stock convention), so their fourteen salts and ten vitamins are not here.
# The isoprenol row already exists (CID 12988, 2026-10-07).
#
# NAMES. A label spelled one way across every dataset is `canonical`, so the record keeps
# the release's spelling and only gains its identifiers. A key spelled two ways (case, or
# two labels PubChem answers with one CID) gets ONE canonical spelling, lowercase in the
# table's style with the stereo prefix kept, and the other spellings become synonyms.
# A label whose CID an EXISTING row already holds is folded into that row as a synonym by
# the merge script (one compound, one node), so it carries no `canonical` here.
#
# LOOKUPS. PubChem's name index is the authority, as for every other list. `query=` is used
# only where the label is a misspelling, a Greek letter or an abbreviation the source itself
# expands; `cid=` only where the name index answers with a record whose structure is not the
# one the name defines (4-aminobutyric acid), or to take the record another label of the
# same substance already resolves to (doxycycline hyclate). Price 2018 Tables S2-S4 state a
# CAS number for 63 of these labels; the merge script looks every one up and records where
# it agrees. Where the CAS and the name give two PubChem records of ONE substance, the
# record another label of that substance already resolves to is taken, so the substance
# stays one node (N-Acetyl-D-Glucosamine, doxycycline hyclate); where the CAS names a
# different FORM than the label (an anhydrous salt for a hydrate, the free acid for a
# sodium salt), the label's form is kept and the conflict is reported.
#
# MIXTURES. Bacitracin, gentamicin and benzalkonium chloride are homologue mixtures whose
# PubChem name record carries one component's structure, so they keep CID/ChEBI and get no
# InChIKey (the tunicamycin rule). Co-trimoxazole is a two-drug combination. Casamino acids,
# Tween 20 and povidone-iodine have no structure at all.
