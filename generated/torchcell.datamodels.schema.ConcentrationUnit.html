torchcell.datamodels.schema.ConcentrationUnit

class ConcentrationUnit(*values)[source]

Bases: StrEnum

UO-aligned units for a dose / physical-factor magnitude (G2 unit typing).

A typed enum (never a free string) so ‘uM’ / ‘µM’ / ‘micromolar’ can never silently coexist across datasets. Temperature units live on TemperatureUnit.

percent is a percent the source reports WITHOUT stating v/v or w/v; never a substitute for percent_v_v / percent_w_v when the source states the basis.
