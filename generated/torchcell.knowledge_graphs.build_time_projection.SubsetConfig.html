torchcell.knowledge_graphs.build_time_projection.SubsetConfig

class SubsetConfig(*, subset_size: int | None = None, per_dataset: dict[str, int | None] = <factory>)[source]

Bases: BaseModel

A KG-build subset config, mirroring the hydra kg_*.yaml subset block.

subset_size caps every dataset (None => full); per_dataset overrides that per DATASET class name (value None => uncapped for that dataset).

cap_for(dataset: str) → int | None[source]

Return the record cap for dataset (None => uncapped/full).

effective_records(dataset: str, full_records: int) → int[source]

Records actually processed = min(cap, full); full when uncapped.
