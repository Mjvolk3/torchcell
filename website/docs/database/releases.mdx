A release is one built knowledge-graph store. The counts quoted on this site, <ReleaseCount field="nDatasets" /> datasets, <ReleaseCount field="nExperiments" /> experiment records and <ReleaseCount field="nGenotypeEnvironmentPairs" /> distinct genotype-environment combinations, are read from the committed snapshot of release <ReleaseCount field="releaseDate" /> at build time.

The details are maintained in the Sphinx docs and are not repeated here:

- [Releases and compatibility](https://mjvolk3.github.io/torchcell/database/compatibility.html):
  release ids, versions, what a release records, and how a release is checked against
  a library version.
- [Dataset downloads](https://mjvolk3.github.io/torchcell/guide/downloads.html):
  versioned dataset archives served alongside the graph.
