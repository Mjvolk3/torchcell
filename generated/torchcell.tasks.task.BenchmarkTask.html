torchcell.tasks.task.BenchmarkTask

class BenchmarkTask(spec: TaskSpec, samples: DataFrame, genes: NDArray[str_], y: NDArray[float64], targets: list[str], excluded: DataFrame, genome: Any, splits: DataFrame | None = None)[source]

Bases: object

A processed benchmark task: samples, genes, labels, genome and pinned splits.

spec

The task definition.

samples

One row per benchmark sample, in label order. Columns include record_index (the row of the source dataset) and key (the locus tag, or two joined by |).

genes

Locus tags of the perturbed genes, shape (n_samples, 1) for a single-gene task and (n_samples, 2) for a gene-pair task.

y

Labels, shape (n_samples, n_targets); nan where a target was not measured for a sample.

targets

Name of each label column.

excluded

Records of the source dataset that are not benchmark samples, each with its exclusion_reason. Nothing is dropped without a row here.

genome

The genome the records are written against.

property split_names: list[str]

Names of the pinned splits.

split(name: str) → Split[source]

The pinned split name.

score(y_true: NDArray[float64], y_pred: NDArray[float64]) → dict[str, float][source]

Mean over targets of each metric; see regression_metrics().
