Planned scope: the graphs that connect genes, how the perturbations of one experiment
are applied over those graphs, and what modeling affordances result. A modeling
affordance is something the data structure lets a model do, for example read the
unperturbed graph, read the perturbed graph, or read only the set of perturbed genes.
The notebook builds each of these views for one experiment record.
