## 2026.09.01 - The flux-variability baseline

Wild-type FVA at 90 % of optimum, which is the reference an amortized sampler is scored
against: width(FVA) minus width(posterior), per reaction. The comparison is label-free, so
it runs on double deletions where no production measurement exists.

Growth 0.0858 h^-1; 1,286 blocked reactions; **2,818 with width <= 1**, which reproduces the
count in [[plan.cgt-metabolism-flux-layer.2026.07.26]] exactly. Restricting to that licensed
set matters, since a reaction FVA leaves free over the full range is not one where narrowing
means anything.
