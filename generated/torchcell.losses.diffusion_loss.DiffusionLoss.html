torchcell.losses.diffusion_loss.DiffusionLoss

class DiffusionLoss(model: Module, *, lambda_diffusion: float = 1.0, lambda_x0: float = 0.0, x0_loss: Module | None = None)[source]

Bases: Module

Strict diffusion loss for conditional decoders.

What it does:

  • computes the model’s diffusion loss

  • (optionally) adds explicit x0 supervision at sampled timesteps

No auxiliary terms, no silent fallbacks.
