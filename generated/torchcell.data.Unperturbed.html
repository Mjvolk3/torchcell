torchcell.data.Unperturbed

class Unperturbed[source]

Bases: GraphProcessor

Preserve the original graph, storing perturbation and phenotype data alongside.

Keeps the base graph structure intact for later perturbation in the pipeline.

This processor: 1. Keeps the original graph structure intact 2. Stores perturbation information separately 3. Records phenotype data without modifying the graph 4. Can be used as a base for applying perturbations later in the pipeline

Attributes remain unchanged:

  • Node features: X ∈ ℝ^(N×d) stays as X ∈ ℝ^(N×d)

  • Edge structure: E ∈ ℤ^(2×|E|) stays as E ∈ ℤ^(2×|E|)
