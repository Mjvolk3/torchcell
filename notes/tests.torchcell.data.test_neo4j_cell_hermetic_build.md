The fixture writes the LMDB in the aggregator's shape (aggregate.py lines 157 to 160: key `"<idx>"`, value the JSON array of `{experiment, experiment_reference}` dumped with `model_dump(mode="json")`) plus `experiment_types.json`; the constructor writes `gene_set.json` and the three index files itself, all under `tmp_path`. Four records over four genes: three fitness records (one double deletion with `fitness_se`, one deletion plus SGA DAmP with `fitness_std`) and one gene interaction. Asserted exactly: `len`, the `get(i)` tensors for all four keys and `None` for a missing key, the read, deserialize and reconstruct round trip by `model_dump()` equality, `label_df` by `assert_frame_equal` plus its parquet cache (a sentinel frame proves the file is read), the five `compute_*_index` dicts and their JSON round trips (int and str keys), re-read-on-access versus memory-cache semantics, `phenotype_labels` selection and order with the unknown-label message, `["fitness"]` giving one value per record with a NaN placeholder on the interaction record, `compute_phenotype_info`, `_copy_lmdb` byte equality, the pickle round trip restoring the read path, environment-variable versus explicit connection settings (no driver constructed), `graphs=` copied with the base graph inserted and the self-loop `edge_index`, `node_embeddings=` giving an exact `gene.x`.
