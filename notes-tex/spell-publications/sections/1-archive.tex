\section{What the archive holds\secstatus{todo}}\label{sec:archive}

The archive is one file, \file{all_spell_datasets.tar.gz}, from
\href{http://sgd-archive.yeastgenome.org/expression/microarray/all_spell_datasets.tar.gz}{the
SGD archive server}. It unpacks to \spellNStudies{} study folders named for the
first author, the year and the PMID, and every PMID is distinct. Each folder
holds a README and one or more PCL files, a PCL file being a tab-separated
matrix of genes by conditions. Across the archive there are \spellNDatasets{}
PCL files and \spellNConditions{} conditions, and the publication years run from
\spellYearMin{} to \spellYearMax{} (Table~\ref{tab:summary}).

\subsection{Where each field comes from\secstatus{todo}}\label{sec:fields}

The PMID, the GEO series and the dataset table are read from the study README.
The README carries no DOI, so the DOI, the PMC id and the journal citation come
from the PubMed record for that PMID, retrieved through the NCBI E-utilities
\texttt{esummary} endpoint and stored beside the manifest in
\file{experiments/015-spell/results/spell_pubmed_esummary.json}.

\spellNDoi{} of the \spellNStudies{} PubMed records carry a DOI. The remaining
\spellNNoDoi{} is linked by its PubMed record alone. \spellNPmc{} records carry
a PMC id, which means PubMed Central holds a full text. Whether that copy is in
the open-access subset served by the PMC OA API was not checked.

The GEO field of a README holds either a bare series id or a PCL filename that
begins with one, and the series id is read from the start of the field. For
\spellNGeoMultiSeries{} studies the PCL filenames name series beyond the one in
the GEO field, and Table~\ref{tab:all} lists those as well.
