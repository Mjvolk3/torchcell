torchcell.data

The data layer between the knowledge graph and model training. ExperimentDataset is the abstract LMDB-backed base for experiment datasets, Neo4jCellDataset queries Neo4j, caches the raw records in LMDB and turns each experiment into a perturbed cell graph, and the graph processors (for example SubgraphRepresentation and LazySubgraphRepresentation) define how a genotype perturbation is applied to that graph. Deduplicators and aggregators merge repeated measurements of the same genotype, and the reference-index helpers group experiments by their shared reference state.

Deduplicate experiments by averaging duplicates of the same genotype.

Aggregator

Abstract base that groups experiment pairs into an aggregated LMDB store.

DeletionKeyedGenotypeAggregator

Aggregator keyed on the DELETION gene set only; other axes are background.

GenotypeAggregator

Aggregator keyed by a hash of the experiment's full perturbation set.

ExperimentDataset

Abstract PyG dataset storing experiment items in an LMDB store.

Neo4jCellDataset

Dataset for loading cell data from Neo4j with file locking for DDP support.

SubgraphRepresentation

Processor that removes perturbed genes and returns the induced subgraph.

LazySubgraphRepresentation

Graph processor that returns full graph with masks instead of filtered subgraphs.

IncidenceSubgraphRepresentation

Graph processor using precomputed node-to-edge incidence structures.

Perturbation

Store only perturbation-specific information without duplicating the graph.

DCellGraphProcessor

Graph processor for DCell model that applies perturbations directly to the gene ontology graph.

Unperturbed

Preserve the original graph, storing perturbation and phenotype data alongside.
