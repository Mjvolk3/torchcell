Neo4j Browser is the web client that ships with Neo4j. It runs Cypher queries and
draws the result as a graph or a table.

## First queries

The release a database holds is recorded in the graph itself. This query returns it:

```cypher
MATCH (r:KgRelease) RETURN r
```

Two built-in Neo4j procedures list what the graph contains without scanning it:

```cypher
CALL db.labels();
CALL db.schema.visualization();
```

The [knowledge graph page of the guide](https://mjvolk3.github.io/torchcell/guide/knowledge-graph.html)
describes the node and relationship types.
